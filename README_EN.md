# 🚀 Agent-Bridge (Meta-Agent Orchestrator)

English | [简体中文](./README.md)

> **"Don't let LLMs write all the code. Let LLMs act as architects to inspect and verify code."**
> 
> Agent-Bridge is a hacker-grade meta-agent orchestrator and command-line tool (CLI). It bridges heterogeneous underlying coding agents (e.g., Claude Code CLI, Cursor, WorkBuddy) to form a fully automated, state-machine-driven dual-agent development pipeline.

---

## 🌟 Architecture & Concept

Traditional multi-agent frameworks often attempt to control everything inside a monolithic runtime, causing hallucination cascading and prompt bloat. Agent-Bridge completely decouples **implementation** and **verification**:

- **Builder**: Implements the current single task defined in `docs/impl.md`, strictly following `docs/tech.md`.
- **Supervisor (Architect/CTO)**: Evaluates the real `git diff`, test outputs, and specifications to emit a strict JSON verdict (`approve` or `reject`).
- **Bridge Orchestrator**: The master daemon managing the file-based state machine, timeout guards, diff truncation, and circuit breakers.

## ⚡ 15-Minute Quickstart

### 1. Installation
```bash
npm install -g agent-bridge
# or run via npx
npx agent-bridge --help
```

### 2. Scaffold a Project
```bash
agent-bridge init
```
Generates:
- `docs/` (`prd.md`, `tech.md`, `impl.md`, `test.md`)
- `agents/` (`supervisor.md`, `builder.md`)
- `prompts/` templates
- `bridge.md` & `.bridge.config.json`

### 3. Configure `.bridge.config.json`
```jsonc
{
  "supervisor": {
    "mode": "api",                   // api | cli | watch
    "provider": "claude",            // claude | openai
    "model": "claude-sonnet-4-5",
    "apiKey": "${ANTHROPIC_API_KEY}"
  },
  "builder": {
    "mode": "cli",
    "command": "claude",
    "args": ["-p", "{promptFile}"],
    "timeoutMin": 45
  },
  "checks": ["npm run build", "npm test"],
  "pollIntervalSec": 5,
  "maxRetryPerTask": 5,
  "onMaxRetry": "human"
}
```

### 4. Run Watcher
```bash
agent-bridge watch
```

## 🛡️ Security & Warnings
- **Supply Chain**: The pipeline executes code generated by LLMs. Run only in isolated sandboxes or Docker containers.
- **Windows CLI Limit**: Always use `{promptFile}` placeholder to avoid the 8191-character command line limit.
